关于这个分类

开发过程中总有一堆零碎需求：临时解一段 Base64、算个 MD5、把 Unix 时间戳还原成可读日期、验证正则是否匹配。为这些事装一个客户端并不划算，但每次翻墙找在线站点又要担心把密钥、Token 粘贴到陌生服务器上。这里的工具全部在本地执行，敏感数据不出浏览器，可放心处理内部配置与凭据。

常见问题

粘贴的密钥和 Token 安全吗？

安全。加密、哈希、编解码全部由浏览器本地 JavaScript 与 Web Crypto API 完成，不会发送到任何服务器。

正则测试支持哪些标志位？

支持 g、i、m、s、u、y 全部 JavaScript 标志位，并实时高亮匹配片段与捕获组。

时间戳转换支持毫秒吗？

支持。可自动识别 10 位秒级与 13 位毫秒级时间戳，并按本地时区与 UTC 双栏显示。
