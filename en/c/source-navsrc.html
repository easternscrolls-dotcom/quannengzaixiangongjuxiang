About this category

A browser bookmark bar stops being useful past a few dozen entries. Turning it into a navigation site lets you group links by purpose and search across them. This source keeps every URL in one config file that takes effect on refresh; cards can show a site icon and a one-line description, and groups collapse independently. Deployed to an internal static server it becomes a shared team start page.

Frequently asked questions

Where do the site icons come from?

By default each site favicon is loaded from its own URL. You can also point entries at local icon files so nothing breaks if the remote link dies.

Can it be used internally by a team?

Yes. Deploy to an internal static server or put basic auth in front of it. The source has no external dependencies or tracking code.

How many groups are supported?

No limit — groups come from a config array and the sidebar scrolls as it grows. Around 20 links per group keeps scanning easy.
