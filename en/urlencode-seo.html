常见问题
Q1：为什么中文链接要编码？
A：URL 仅能安全传输部分 ASCII 字符，中文及特殊符号需转为 %XX 形式才能被服务器正确识别。
Q2：编码和解码有什么区别？
A：编码把特殊字符转为安全格式；解码把 %XX 还原为原始字符。
Q3：解码提示失败怎么办？
A：说明输入不是合法的编码文本，请确认来源内容是否完整。
Q4：数据会上传吗？
A：不会，全程浏览器本地处理。
Q5：处理后的链接会失效吗？
A：不会，编解码仅做格式转换，不改变链接指向，处理后即可正常使用。
Q6：SEO友好URL可以在手机上使用吗？
A：可以，本工具基于网页运行，手机、平板、电脑均可直接打开网页使用，无需安装 App。
FAQ
Q1: Why encode Chinese characters in a URL?
A: URLs safely transmit only some ASCII chars; Chinese and special characters must be converted to %XX so servers read them correctly.
Q2: What's the difference between encode and decode?
A: Encoding turns special chars into a safe format; decoding turns %XX back to the original characters.
Q3: Decode failed — what now?
A: The input isn't valid encoded text; make sure the source is complete.
Q4: Is my data uploaded?
A: No, everything is processed locally in your browser.
Q5: Will the processed link break?
A: No, encoding/decoding only changes the format, not where the link points.
Q6: Can I use it on mobile?
A: Yes, it runs in any browser — no app needed.
