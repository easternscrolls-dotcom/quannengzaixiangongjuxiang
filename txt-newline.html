功能介绍与适用场景

换行符转换是一款免费的在线开发工具，无需下载安装、无需注册登录，打开网页即可使用。不同操作系统使用不同的换行符：Windows 用 CRLF（回车+换行）、Unix/Mac/Linux 用 LF、旧版 Mac 用 CR。本工具会先把文本统一归一，再转换为你选择的目标换行符，解决跨平台打开文件时出现的多余空行、显示错乱或 Git 提示换行差异等问题。所有处理均在浏览器本地完成，数据不上传服务器。

换行符转换适用于在 Windows 与 Linux/Mac 之间迁移代码与脚本、修复 Shell 脚本因 CRLF 无法执行、统一团队仓库换行风格、处理配置文件与数据文件等场景。作为一款轻量在线工具，它免去了在编辑器里逐一设置的麻烦，随开随用，是开发调试与运维处理中的实用小工具。

使用教程
  1. 粘贴文本到输入框，或选择一个 .txt 文件自动载入。
  2. 选择目标换行符（LF、CRLF 或 CR）。
  3. 点击「转换换行符」，浏览器本地完成归一与转换。
  4. 点击「下载结果」保存换行符已统一的文件。
常见问题
Q1：为什么结果看起来没变化？
A：换行符差异在文本框中不可见，转换效果在下载的文件里生效，可用支持显示换行符的编辑器查看。
Q2：CRLF 和 LF 有什么区别？
A：CRLF 是 Windows 换行，LF 是 Unix/Mac/Linux 换行，混用会导致空行或脚本报错。
Q3：数据会上传吗？
A：不会，全部在浏览器本地处理。
Q4：会破坏文件内容吗？
A：不会，仅统一换行符，正文内容完全保留。
Q5：Git 老提示换行符警告怎么办？
A：可用本工具把文件统一为 LF，或配置 Git 的 core.autocrlf；统一换行风格后警告即消失。
换行符转换可以在手机上使用吗？
A：可以，本工具基于网页运行，手机、平板、电脑均可直接打开网页使用，无需安装 App。
